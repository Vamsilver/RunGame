# RunGame

Учебный 3D-проект на Unity 6 с камерой Cinemachine, анимированными бонусами,
монетами и кошельком, системой здоровья, интерактивными препятствиями и
эффектами частиц.

## Требования

- Unity 6.5 (6000.5.6f1)
- Universal Render Pipeline
- Cinemachine 3

Подробное описание управления и механик будет добавлено после завершения
демонстрационной сцены.
