# RunGame

Небольшая 3D obstacle-course игра для портфолио. Проект демонстрирует настройку
Cinemachine, Animator state machine, физические триггеры, сбор предметов,
систему здоровья и эффекты частиц.

## Реализовано

- плавное слежение камеры за игроком через **Cinemachine Camera**;
- заметная бонусная зона на маршруте с состояниями Animator `Idle` и `Active`;
- переключение анимации бонуса при входе и выходе игрока из trigger-зоны;
- prefab монеты, подбор монет, кошелёк и счётчик в HUD;
- здоровье игрока и индикатор HP;
- вращающаяся перекладина и движущийся пресс, наносящие урон;
- взрывоопасные бочки: столкновение быстрее заданного порога уничтожает игрока;
- скоростная система пылевых частиц, которая работает только во время движения;
- перезапуск демонстрационной сцены.

## Управление

| Действие | Клавиши |
|---|---|
| Перемещение | `WASD` или стрелки |
| Перезапуск сцены | `R` |

## Запуск

1. Установить Unity Hub и Unity `6000.5.6f1`.
2. Клонировать репозиторий.
3. Открыть корневую папку проекта через Unity Hub.
4. Открыть `Assets/Scenes/PortfolioDemo.unity`.
5. Нажать **Play**.

Unity автоматически восстановит зависимости из `Packages/manifest.json`.
Папки `Library`, `Temp`, `Logs` и другие генерируемые данные намеренно не
хранятся в репозитории.

## Основные компоненты

| Компонент | Назначение |
|---|---|
| `PlayerController` | Физическое перемещение игрока через Rigidbody |
| `BonusTriggerAnimator` | Передача состояния trigger-зоны в Animator |
| `Wallet` / `CoinPickup` | Хранение и сбор монет |
| `PlayerHealth` | Получение урона и уничтожение игрока при 0 HP |
| `OscillatingObstacle` | Движение кинематических препятствий |
| `ExplosiveBarrel` | Проверка силы столкновения и взрыв |
| `MovementParticleController` | Включение частиц по скорости игрока |

## Как проверить критерии

- В Hierarchy объект `CM Virtual Camera - Player Follow` содержит
  `CinemachineCamera`, `CinemachineFollow` и `CinemachineRotationComposer`, а
  основная камера — `CinemachineBrain`.
- Бонус стоит непосредственно на маршруте внутри светящегося круга. При входе
  игрока параметр Animator `PlayerNearby` переключает `Idle` на `Active`; при
  выходе происходит обратный переход.
- Вращающаяся перекладина и движущийся пресс отнимают HP. Столкновение с
  зелёной бочкой на скорости выше `5.5` мгновенно уничтожает игрока.
- Пыль у ног появляется только при движении, а интенсивность зависит от скорости.

## Техническая информация

- Unity `6000.5.6f1` (Unity 6.5)
- Universal Render Pipeline `17.5.0`
- Cinemachine `3.1.7`
- Input System `1.20.0`
- целевая платформа: Windows

Проект использует только встроенные примитивы и материалы, поэтому не требует
сторонних ассетов или отдельных лицензий.
