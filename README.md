# RunGame

Портфолио-проект на Unity 6: процедурная obstacle-course игра с Cinemachine, Animator, физическими препятствиями, монетами, HP и системами частиц.

## Быстрый запуск

1. Установите через Unity Hub редактор **Unity 6000.5.6f1**.
2. Клонируйте репозиторий и добавьте его корневую папку в Unity Hub.
3. Дождитесь импорта пакетов и компиляции скриптов.
4. Основная сцена `Assets/Scenes/ProceduralRun.unity` откроется автоматически.
5. Нажмите **Play**.

Если автоматическое открытие не сработало, дважды нажмите на файл:

`Assets/Scenes/ProceduralRun.unity`

`ProceduralRun` также стоит первой сценой в Build Settings, поэтому собранная игра всегда запускается с неё.

## Управление

| Действие | Клавиши |
|---|---|
| Перемещение | `WASD` или стрелки |
| Следующий уровень | Кнопка `NEXT LEVEL` после финиша |

## Выполненные требования

- слежение за игроком через Cinemachine Camera, Follow и Cinemachine Brain;
- бонус с Animator State Machine (`Idle`/`Active`) и переходами при входе и выходе из trigger-зоны;
- prefab монетки, сбор монет, кошелёк и счётчик в HUD;
- взрывные бочки с проверкой силы столкновения;
- подвижные и вращающиеся препятствия, урон, HP и уничтожение игрока;
- круглые частицы движения, поднимающиеся вверх и исчезающие от белого к прозрачному серому.

## Дополнительные возможности

- детерминированная процедурная генерация уровня по seed;
- шесть типов prefab-модулей без соседних повторов;
- новый уровень получает дополнительный модуль и повышенную сложность;
- сохранение HP и монет между успешно завершёнными уровнями;
- откат состояния после смерти;
- лечебный бонус `+25 HP` один раз на экземпляр;
- финишный танец, приближение Cinemachine и кнопка следующего уровня;
- процедурный город из prefab-домов, деревьев, машин и перекрёстков;
- чёрно-белая шахматная финишная полоса.

## Основные компоненты

| Компонент | Назначение |
|---|---|
| `PlayerController` | Физическое перемещение игрока |
| `BonusTriggerAnimator` | Управление Animator бонуса из trigger-зоны |
| `CoinPickup` / `Wallet` | Сбор и хранение монет |
| `PlayerHealth` | Получение урона, лечение и смерть |
| `ExplosiveBarrel` | Проверка силы столкновения и уничтожение игрока |
| `DamageObstacle` | Нанесение урона подвижными препятствиями |
| `MovementParticleController` | Интенсивность частиц в зависимости от скорости |
| `ProceduralRunManager` | Генерация модулей, окружения и финиша |

## Техническая информация

- Unity `6000.5.6f1`
- Universal Render Pipeline `17.5.0`
- Cinemachine `3.1.7`
- Input System `1.20.0`
- основная сцена: `Assets/Scenes/ProceduralRun.unity`
- дополнительная демонстрационная сцена: `Assets/Scenes/PortfolioDemo.unity`

Папки `Library`, `Temp`, `Logs`, `Builds` и другие генерируемые данные не хранятся в репозитории.
